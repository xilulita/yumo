语墨 · 安装与使用说明

DESKTOP EDITION · 本地运行，数据不出电脑

第一次使用

  1. 打开程序，点右下「设置」。
  2. 选服务商预设，填写 API Key，点「保存并测试」。
  3. 看到「连通正常」即可出题；做图片批改需选支持读图的模型（如 qwen-vl-max、gpt-4o）。
密钥只保存在本机配置文件里，不会上传到任何地方。导出的备份文件不含密钥。

常用快捷键

快捷键作用
Ctrl+N新建试卷
Ctrl+O跳到批改页
Ctrl+S导出学生数据备份
Ctrl+P打印当前页面
Ctrl++ / -放大 / 缩小界面

批改作业

三种方式都可以：

  • 点「选择图片」，从电脑里挑作业照片；
  • 直接把照片拖进窗口；
  • 截图后按 Ctrl+V 粘贴。

导出与打印

  • 试卷生成后，可开关「导出时附带答案」，再点导出，弹出系统「另存为」对话框。
  • 导出的 HTML 用浏览器打开即可打印，答案单独排在卷末页。
  • Ctrl+P 可直接调用系统打印。

数据安全

  • 学生档案、错题、试卷都存在本机，卸载程序会一并删除。
  • 建议每周用 Ctrl+S 导出一次备份，存到网盘或 U 盘。
  • 换电脑时，在新机器上用「设置 → 导入备份」恢复。

常见问题

提示「无法连接接口」　先确认能上网；再核对 Base URL 是否以 /v1 结尾；开了代理或 VPN 的话先关掉试试。

提示接口返回 401 / 403　密钥错误或没有该模型权限，去服务商控制台确认密钥有效、模型已开通。

图片批改读不出题目　换支持视觉的模型；照片尽量正对、光线均匀、整页入镜。

窗口太小或布局挤　按 Ctrl+0 恢复实际大小，或把窗口拉宽到 1100 像素以上。
